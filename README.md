# 🍎 Keloğlan'ın Elma Diyarı – Python Değişkenler

## Proje Hakkında
Bu proje, Python programlama dilinde değişkenlerin oluşturulmasını, değişkenlere değer atanmasını ve temel aritmetik işlemlerin gerçekleştirilmesini öğrenmek amacıyla hazırlanmıştır.

## 1. Proje Ne Yapıyor?
Keloğlan'ın 3, Balkız'ın 5 ve Keloğlan'ın Anası'nın 6 elması bulunmaktadır.

Program:
- Elma sayılarını değişkenlerde saklar.
- Değişkenlerin değerlerini ekrana yazdırır.
- Elmaların toplam sayısını hesaplar.
- Toplama, çıkarma, çarpma ve bölme işlemlerini örneklendirir.

## 2. Proje Neden Faydalı?
- Python'da değişken kullanımını öğretir.
- Veri türleri ve değer atama mantığını pekiştirir.
- Aritmetik operatörlerin kullanımını gösterir.
- `print()` fonksiyonunun kullanımını öğretir.

## 3. Proje Nasıl Çalıştırılır?
1. Bilgisayarda Python 3 kurulu olmalıdır.
2. `elma_diyari.py` dosyası indirilir.
3. Dosya Python IDLE üzerinden açılır.
4. F5 tuşuna basılarak çalıştırılır.
5. İşlem sonuçları IDLE Shell ekranında görüntülenir.

## 4. Kullanılan Teknolojiler

- Geliştirme ortamı: Python IDLE
